## Data status

The proprietary Matrix calculations are functional and update instantly from the supplied inputs. The included starter board is **model input data**, not a claim of a live 2026 projection feed. Users can add current player inputs from a trusted fantasy source now. A future data-provider phase can automate those inputs while keeping the Matrix scoring layer separate.
